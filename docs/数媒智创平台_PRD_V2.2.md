2. 产品概述

2.1 产品名称与定位

产品名称：数媒智创平台（https://x.sztv.com.cn）

产品定位：面向媒体行业与内容创作者的一站式AI智能内容生成平台，集成大模型对话、热点聚合、知识库管理、AIGC内容生产与AI技能市场，帮助用户提升选题、创作、配音、视频生成等全链路效率。

2.2 目标用户

媒体记者、编辑、策划人员：需要快速追踪热点、生成选题与稿件

新媒体运营：需要跨平台内容适配、标题优化、短视频生成

内容创作者：需要AI辅助的图片、视频、音频生产

技术与业务管理员：需要管理企业知识库、发布与订阅AI技能

2.3 核心价值

热点感知：聚合国内外多平台热搜，提供实时选题参考

智能创作：基于多模型AI对话与专业智能体，快速生成文本、图片、视频、音频

知识沉淀：通过知识库实现企业文档的RAG检索与智能问答

技能扩展：SkillHub支持社区化AI技能共享，满足垂直业务场景

3. 功能架构

平台采用“主站 + 独立子系统”的架构：

主站（x.sztv.com.cn）：统一工作台，承载新建任务、热点榜单、历史记录、导航入口

创作子站（geekai.sztv.com.cn）：图片生成、视频创作等AIGC生产工具

知识库子站（weknora.scms.sztv.com.cn）：企业级RAG知识库管理（WeKnora）

技能市场子站（SkillHub）：AI技能发布、搜索与订阅

4.4 热点助手

4.4.1 功能定位

热点助手是基于热点榜单数据的进阶热点分析工具，面向编辑、策划与运营人员，提供热点搜索、热点预测与事件深度分析能力。与热点榜单“看榜”不同，热点助手强调“查热点、跟热点、分析热点”，支持按行业、地域、时间等维度检索与预测热点事件。

4.4.2 页面结构

热点助手采用“顶部脉搏 + 中部筛选 + 下部列表”的纵向布局：

顶部：实时热点脉搏滚动条，展示当前正在发酵的热门话题与热度变化（如“深圳今日热点脉搏 ↑289”）。

中部：双Tab切换（热点搜索 / 热点预测）+ 多维度筛选面板。

下部：热点事件卡片列表，每张卡片展示分类、地域、标题、摘要、热度与阅读量，并支持“查看详情”。

4.4.3 热点搜索

热点搜索支持用户主动检索平台已收录的热点事件：

行业分类：全部行业（默认），可切换更细分的垂类。

地域：按省/市/自治区筛选，默认“请选择地域”。

内容发布时间：通过日期区间过滤事件发现或内容发布时间。

搜索关键词：支持事件名称、媒体内容标题、摘要等关键词模糊搜索。

操作：点击“搜索”执行筛选，点击“重置”清空条件。

数据更新时间：页面展示当前热点数据的更新时间（如“2026/07/14 09:23”）。

4.4.4 热点预测

热点预测通过算法模型对潜在热点进行提前识别，帮助编辑提前布局：

排序方式：默认“热度变化降序”，优先展示热度快速上升的事件。

预测类型：

热度飙升：热度增长速度最快的事件。

新上榜：新进入榜单或新被发现的事件。

等级跃升：热度等级发生跨级跃升的事件。

卡片信息：除标题、摘要外，额外展示热度变化值（如“+6284”）、地域标签与发现时间。

4.4.5 事件详情

点击“查看详情”进入事件详情页（URL: /hotspot-assistant/detail/{id}?from=search|forecast），详情页包含：

基础信息：标题、事件等级、行业分类、地域、发现时间、状态（在线/已下线）。

核心指标：当前热度、阅读量、相关文章数、相关视频数。

事件简介：结构化的事件摘要，帮助用户快速理解事件背景。

事件脉络：展示事件发展关键节点（当前版本显示“暂无脉络数据”，说明该能力尚未完全接入数据）。

热度趋势：支持近24小时 / 近7天切换的趋势图表，反映热度变化走势。

4.4.6 与热点榜单的关系

热点榜单：提供“多平台聚合榜单”，解决“当前什么热”的问题。

热点助手：提供“热点检索与预测”，解决“我想找什么热点、未来可能火什么”的问题。

两者数据互通：热点助手中的事件可被视为热点榜单的深化分析，热点榜单中的条目可作为热点搜索/预测的入口补充。

5. 典型业务流程

5.1 热点选题流程

1. 用户进入“热点榜单”，切换国内/国际Tab查看实时热搜，或使用“热点助手”按行业/地域/关键词检索/预测热点

2. 发现感兴趣话题后，点击“查看详情”进入事件详情页，了解热度、阅读量、事件简介与趋势

3. 在热点助手或首页点击对应智能体（如【国内】多平台热搜聚合分析智能体），进入智能体对话

4. 在智能体对话中点击“开始执行任务”，平台调用热搜接口抓取数据并生成分析报告

5. 若接口异常，系统提示“网络发生波动，请稍后重试”

5.2 AIGC内容生产流程

1. 用户进入“生产工具”→“内容创作”

2. 选择图片生成或视频创作，填写提示词、选择模型与参数

3. 点击“立即生成”，任务进入任务列表

4. 生成完成后在“创作记录/你的作品”中查看、下载、删除

5.3 数字主播视频生产流程

1. 进入“数字主播”

2. 第一步选择数字人形象（实景/动态/绿幕/半身/全身）

3. 第二步选择播报音色

4. 第三步输入文案，点击生成

5. 在生成历史中下载成品视频

5.4 知识库问答流程
